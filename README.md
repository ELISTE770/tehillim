# תהילים — אפליקציית Windows

תהילים שנבנה מתוך `il.avimak.Tehillim` v3.1.5 (APK לאנדרואיד).
**לא אמולטור** — התוכן חולץ, לוגיקת החלוקה תורגמה, ונבנתה אפליקציית Windows.

השם והאייקון מהמקור: `app_name` = "תהילים", והאייקון מ־`res/drawable-xxhdpi/ic_launcher.png`.

## מה שונה כאן — בחירה בין טקסט לתמונה

בניגוד לסידור (עמודי תמונה בלבד), לתהילים כבר היה טקסט מנוקד מלא בתפילולרי
(150 קפיטלים + פיצול קי"ט, 183,609 תווים). לכן כאן יש **הגדרה שמאפשרת
לבחור טקסט או תמונה** לכל קריאה — ברירת המחדל היא טקסט, עם אפשרות מיידית
להחלפה בסרגל העליון בלי לצאת מהקריאה הנוכחית.

**חריג אחד:** 22 "פרקי האותיות" (kyt1–kyt22, לשימוש ביארצייט וברפואה שלמה
לפי אותיות השם) ושמונה תפילות נלוות (לפני/אחרי התהילים, ברכת בית הקברות,
קדיש יתום, קל מלא רחמים, ויהי רצון לרפואה שלמה) קיימים במקור רק כתמונה —
לא נמצא עבורם טקסט מנוקד מאומת, ולכן הם מוצגים תמיד כתמונה עם ציון מפורש
של כך. כל שאר האפליקציה — כולל היום־בחודש, היום־בשבוע, חמשת הספרים,
כל 150 הפרקים, כל הסגולות והתיקון הכללי — משתמשת אך ורק בפרקים רגילים,
ולכן זמינה במלואה בשני המצבים.

## החלוקות — זהות למקור

`lib/tehillim.js` הוא תרגום ישיר של `Tehillim.java` המפורק, אינדקס-אינדקס:

| חלוקה | טווח | הערה |
|---|---|---|
| יום בחודש | 1–30 | יום 29/30 תלוי אם החודש מלא (ל') או חסר (כ"ט) |
| יום בשבוע | א'–ש"ק | לפי יום השבוע **האזרחי** הנוכחי — כך גם במקור |
| חמשת הספרים | ספר א'–ה' | המקור מדלג על פרקי המפריד 41, 72, 89, 106 — הועתק כלשונו, לא תוקן |
| ג' פרקי אלול | מר"ח אלול עד יוה"כ | יום אלול N → פרקים 3N-2..3N; ממשיך לתשרי ברצף מצטבר |
| סגולות | 7 סוגים | רפואה שלמה, פרנסה, שלום בית, לידה, פריון, שידוכים, הריון |
| תיקון הכללי | 10 פרקים קבועים | רבי נחמן מברסלב |
| יארצייט / רפואה שלמה | לפי אותיות השם | 22 פרקי-אותיות + פרקים קבועים, תמונה בלבד |

**קפיטל קי"ט** מפוצל לשני חלקים בכל מקום שהוא מוזכר — בדיוק כמו במקור,
שמחזיק `t119`/`t119b` כשני משאבים נפרדים.

**"פרק ליום ללא-תחנון"** (קפיטל כ') מופיע במסך "יומי" רק בימים שאין בהם
תחנון, בדיוק כמו הכפתור המקביל במקור. הבדיקה משתמשת באותה שכבת
תאימות ל-KosherJava שנבנתה עבור הסידור (`lib/jewish.js`).

**"יום בשבוע" הוא יום אזרחי, לא עברי** — כך גם במקור: הקוד המפורק קורא
`Calendar.getInstance().get(DAY_OF_WEEK)`, לא תאריך עברי, ואין גלגול
שקיעה בשום מקום באפליקציה הזו (בניגוד לתפילולרי ולסידור). התאריך העברי
לחישוב "יום בחודש" ו"אלול" מחושב מהתאריך האזרחי הנוכחי בלבד.

## אימות

`npm run verify` מריץ את כל החלוקות (חודש מלא/חסר, כל 7 ימות השבוע,
חמשת הספרים, כל 150 הפרקים, 39 ימי אלול-עשי"ת, כל הסגולות, יארצייט
ורפואה שלמה) ומוודא שכל פריט מצביע על קובץ טקסט **וגם** קובץ תמונה
שקיימים בפועל, ושכל 150 הפרקים מכוסים בחלוקות הבלעדיות (חודש/שבוע) בלי
חוסר.

## "הפרקים שלי"

גרסה מפושטת של תכונת ה-My Chapters המקורית (שנשענה על מסד SQLite
ועל חשבון-חודשים עברי מורכב). כאן: רשומה קבועה (קפיטל תמיד זהה) או
רשומת-תאריך (קפיטל מתקדם ביום, חוזר לתחילת המחזור אחרי ק"נ) — מבוססת
על הפרש ימים אזרחי פשוט, ששקול לגמרי להפרש ימים עברי (יום הוא יום
בשתי השיטות). נשמר ב-localStorage מקומי, לא בענן.

## מבנה

```
main.js              תהליך Electron — חלון ו-IPC בלבד
lib/tehillim.js       מנוע ההרכבה — תרגום ישיר של Tehillim.java
lib/jewish.js         שכבת תאימות ל-KosherJava (משותפת עם הסידור)
lib/core.js           תאריכים, הגשת טקסט/תמונה, הרכבת "היום"
lib/updater.js         בדיקת עדכונים מול גיטהאב
renderer/              הממשק — שני טאבים ("יומי"/"סייר") כמו במקור
content/text/          151 קבצי HTML מנוקדים (150 פרקים + פיצול קי"ט)
content/images/        181 עמודי PNG (150+1 פרקים + 22 קיט + 8 מיוחדים)
tools/verify-tehillim.js  אימות מנוע ההרכבה
tools/build-win.js        בנייה בשלושה שלבים
```

## פקודות

```bash
npm start      # הרצה
npm run dev    # שרת בדיקה בדפדפן
npm run verify # אימות מנוע ההרכבה
npm run dist   # בניית מתקין + גרסה ניידת
```

יש לבנות מנתיב קצר. מהמורות הבנייה (`app-update.yml`, `winCodeSign`,
`rcedit`) זהות לאלה של תפילולרי והסידור, ומטופלות ב-`tools/build-win.js`.
