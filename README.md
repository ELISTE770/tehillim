# תהילים — אפליקציית Windows

הומר מ־APK אנדרואיד (`il.avimak.Tehillim` גרסה 3.1.5) לאפליקציית Windows
אמיתית — **לא אמולטור, לא עטיפה**. התוכן חולץ מהמקור, לוגיקת החלוקה
תורגמה שורה-שורה מהקוד המפורק, ונבנתה אפליקציית Electron עצמאית.

## מה יש בתיקייה הזו

| קובץ/תיקייה | מה זה |
|---|---|
| `Tehillim-Setup-1.3.0.exe` | מתקין רגיל — מריצים ועוקבים אחרי ההוראות. שואל אם ליצור קיצור דרך בשולחן העבודה |
| `Tehillim-Portable.exe` | גרסה ניידת — רצה בלי התקנה, אפשר להעביר בין מחשבים ע"ג USB |
| `מקור\` | קוד המקור המלא, ניתן לבנייה מחדש (ראו `מקור\README.md`) |
| `APK מקורי\` | קובץ ה-APK המקורי של אנדרואיד שממנו הופקה האפליקציה |

## התקנה

בהרצה הראשונה **Windows SmartScreen** עשוי להזהיר "Windows protected your PC"
כי הקובץ אינו חתום בחתימה דיגיטלית (רכישת תעודת חתימה עולה כסף ולא
נעשתה עבור פרויקט אישי זה). זה תקין וצפוי — לחצו **"מידע נוסף"** ואז
**"הפעל בכל זאת"**.

## מה האפליקציה עושה

מבנה זהה למקור — שני טאבים:

- **יומי**: תהילים ליום בחודש, תהילים ליום בשבוע, ג' פרקי אלול (בעונה
  המתאימה, מר"ח אלול עד יום הכיפורים), פרק ליום ללא-תחנון (רק בימים
  שאין בהם תחנון), יהי רצון (לפני/אחרי אמירת תהילים), כל 150 הפרקים,
  והפרקים שלי (רשימת קריאה אישית)
- **סייר**: חיפוש פרק ספציפי, בחירת אחד מחמשת הספרים, יום בשבוע/בחודש
  ספציפי, התיקון הכללי (רבי נחמן מברסלב), יארצייט/רפואה שלמה לפי אותיות
  השם, 7 סוגי סגולות (רפואה שלמה, פרנסה, שלום בית, לידה, פריון, שידוכים,
  הריון), ופרק אקראי

**בחירה בין טקסט לתמונה** — התכונה שביקשת: לכל אחד מ-150 הפרקים יש גם
טקסט מנוקד מלא וגם תמונת עמוד מקורית, עם מתג בראש המסך שמחליף באופן
מיידי בלי לצאת מהקריאה הנוכחית. ברירת המחדל היא טקסט.

**חריג אחד, מתועד ומוצג למשתמש**: 22 "פרקי האותיות" (המשמשים ליארצייט
ורפואה שלמה, כל פרק מייצג אות בשם) ושמונה תפילות נלוות (יהי רצון,
ברכת בית הקברות, קדיש יתום ועוד) קיימים במקור רק כתמונה — לא היה עבורם
טקסט מנוקד מהימן במקורות שנבדקו. במקרים אלה מוצגת התמונה עם הודעה
מפורשת שהתוכן קיים רק כתמונה. כל שאר האפליקציה זמינה במלואה בשני
המצבים.

**כל חלוקות התוכן זהות למקור, כולל "מוזרויות" מכוונות** שנשמרו בכוונה
ולא "תוקנו": חמשת הספרים מדלגים על פרקי מפריד (41, 72, 89, 106) בדיוק
כמו באפליקציה המקורית, ו"יום בשבוע" מחושב לפי היום ה**אזרחי** (לא יום
עברי, ובלי גלגול שקיעה) — כך פועל גם המקור. פירוט מלא בטבלה בתוך
`מקור\README.md`.

יש התראה על עדכון גרסה חדשה (בדיקה אוטומטית + ידנית בהגדרות), עם אישור
מפורש לפני התקנה — האפליקציה לעולם לא מתקינה עדכון בלי לחיצה שלך.

## בנייה מחדש מהמקור

```bash
cd "מקור"
npm install
npm start        # הרצה רגילה
npm run verify    # אימות מנוע חלוקת התוכן
npm run dist      # בניית מתקין + גרסה ניידת (דורש נתיב קצר, ראו README.md הפנימי)
```

## היסטוריית גרסאות

- **1.3.0** — ממשק משתמש דו-לשוני מלא (עברית ואנגלית): מתג שפה מהיר (EN / עב) בראש החלון, בחירת שפה בהגדרות, תמיכה מלאה ב-LTR והיפוך פריסה, תאריכים עבריים ולועזיים באנגלית, ו-124 מפתחות תרגום לכל רכיבי האפליקציה.

- **1.2.0** — דפדוף בין ימים (יום קודם/הבא + בורר תאריך) עם פס אזהרה
  בולט כשמוצג יום שאינו היום, ו"המשך מהמקום שהפסקת" ככרטיס במסך היומי.

- **1.1.0** — חיפוש בכל התהילים (מתעלם מניקוד), מצב כהה אמיתי לעמודי
  התמונה, גודל טקסט מהסרגל העליון, זכירת גודל ומיקום החלון, מופע יחיד,
  קיצורי מקלדת והדפסה. תוקן: לא הייתה דרך לחזור ל"התאם לרוחב", וסטייה
  אפשרית של יום ב"הפרקים שלי" בשעון קיץ.

- **1.0.2** — הרשימה בסרגל הצד (מתחת לטאבים) כבר לא ריקה כשמסך "יומי"
  פתוח: היא מציגה כברירת מחדל את תפריט הניווט של "סייר" (פרק ספציפי,
  ספר, יום בשבוע/בחודש, סגולות וכו'), בעוד שתוכן המסך הראשי ממשיך
  להיפתח כברירת מחדל על "לימוד היום" — כמו במקור. לחיצה על פריט ברשימה
  עוברת לקריאה המבוקשת ומסמנת את טאב "סייר" בהתאם.
- **1.0.1** — תיקון פריסה: בחלון צר (מסך קטן, סקיילינג גבוה) התוכן הראשי
  היה יכול להיראות ריק לגמרי. עכשיו הפריסה מסתגלת לרוחב החלון ותמיד
  מציגה את התוכן. נוסף גם מסך שגיאה גלוי למקרה של תקלת טעינה, במקום
  מסך ריק שקט.
- **1.0.0** — גרסה ראשונה.
